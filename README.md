# Ramayana ASCII

A Python ASCII animation that uses words from the Ramayana to depict Rama’s last arrow, Ravana’s fall, and Ayodhya lighting up for Diwali.

## Run locally

Use Python 3.11 or newer with Tkinter. Tkinter is included with the standard Windows installer and may need to be installed separately on Linux.

On Windows, run these commands from the project folder.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe play.py
```

On macOS or Linux, use the following commands.

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python play.py
```

The animation plays as soon as the window opens. Press **R** to replay or **Esc** to close it.
